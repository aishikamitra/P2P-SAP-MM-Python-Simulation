## Procure-to-Pay (P2P) System - SAP MM Simulation

## Overview
This project simulates the Procure-to-Pay (P2P) cycle based on SAP MM using Python.

## Process Flow
PR → PO → GR → Invoice → Payment

## Features
- Vendor management
- Inventory tracking
- Purchase workflow simulation

## How to Run
Download the project and run:
python p2p_system.py

## Note
This is a simulation inspired by SAP MM.
